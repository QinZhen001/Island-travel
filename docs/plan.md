## 三天行程

### Day 1｜10 月 5 日：上岛、看海、吃海鲜

| 时段 | 安排 | 提示 |
| --- | --- | --- |
| 上午 | 到蛇口邮轮中心，乘船登岛 | 早餐提前吃好，证件和乘船码拿好 |
| 中午 | 下船找民宿、安顿行李、简单吃午饭 | 民宿不提供接送，预留找楼栋和联系前台的时间 |
| 下午 | 办理入住，洗漱休息；再去石涌湾沙滩、双子亭一带散步拍照 | 想下水先看现场开放与救生安排，不下水也很好逛 |
| 傍晚 | 玉带环腰沿海步道，找个开阔点一起看晚霞 | 天黑前离开偏僻路段 |
| 晚上 | 海鲜晚餐，之后去伶仃湾广场、拱桥附近走走 | 在有照明的公共区域活动，早点回酒店休息 |

**游玩顺序：** 民宿 → 石涌湾沙滩 / 双子亭 → 玉带环腰开放步道 → 晚餐 → 伶仃湾广场、拱桥 → 回民宿。入口和连接路段以上岛后的导览牌为准。[景点位置与介绍](https://m.zh.bendibao.com/jingdian/zhuhaiwailingdao/content/)

**想留下的照片：** 船靠岸时的岛屿全景、海边双人合照、晚霞里的背影。第一天挑两三个喜欢的位置就够，别赶场。

### Day 2｜10 月 6 日：登高看海，下午彻底放松

| 时段 | 安排 | 提示 |
| --- | --- | --- |
| 早上 | 早餐补水，向民宿确认登山步道开放情况后出发 | 穿防滑运动鞋，带饮水、防晒和小零食 |
| 上午 | 伶仃峰、石景公园方向徒步，往返含拍照休息 | 体力和天气不行就果断换成海边步道 |
| 中午 | 回镇上午餐，回民宿午休 | 不紧接着安排长距离步行 |
| 下午 | 二选一：镇上喝咖啡慢慢逛；或去矿石湖观景 | 矿石湖需当天确认是否开放，不确定就不去 |
| 傍晚 | 回到喜欢的海边点位，看海、补拍 | 也可以直接回房间躺着 |
| 晚上 | 晚餐，确认次日船班、整理行李 | 收到风浪或船班通知优先处理返程 |

**登山路线：** 从镇上沿现场标识进伶仃峰步道，途经北帝晨钟等开放节点，到石景公园与山顶观景区域后按标识原路返回。**不把不明岔路当捷径**，具体走向让民宿在导览图上标出来。[官方旅游手册中的外伶仃岛介绍](https://content.macaotourism.gov.mo/uploads/mgto_brochures/68fdeff1fdcf6aca24a5b36a8084a13f0e504b3f.pdf)

**想看日出：** 前一晚再查日出时间、天气和步道开放情况，只去民宿确认能安全到达的观景点。

### Day 3｜10 月 7 日：早餐、最后一次海边散步、回深圳

| 时段 | 安排 | 提示 |
| --- | --- | --- |
| 早上 | 慢慢吃早餐，再看一眼当天船班动态 | 确认 15:30 回程有无变更 |
| 上午 | 海边散步，补拍喜欢的点位 | 不安排登山、出海等耗时难控的项目 |
| 中午 | 回民宿收拾、退房，附近吃午饭 | 12:00 前离店；不能寄存就把行李带在身边 |
| 下午 | 码头周边喝咖啡休息，取行李清点证件，14:30 到码头 | 民宿无接送，出门时间按确认好的路线倒推 |
| 傍晚 | 安检候船，15:30 开船，17:00 抵蛇口 | 下船后另留出港与市内交通时间 |

## 吃什么

- **第一晚认真吃一顿海鲜**：鱼或虾选一道 + 贝类一道 + 蔬菜 + 主食，两人先少点，不够再加。
- 其余餐次轻松解决：粉面、粥、包点、家常菜，早餐简单吃。
- 岛上特色可以挑一两样尝尝（海胆、狗爪螺、将军帽），不必一次点齐。[海岛美食介绍](https://content.macaotourism.gov.mo/uploads/mgto_brochures/68fdeff1fdcf6aca24a5b36a8084a13f0e504b3f.pdf)
- 两个人吃省心起见，选**明码标价**的餐馆；若去市场买了再加工，先确认购买价、称重单位和加工费再付款。

## 天气

本计划不预设三天天气。10 月 3 日、4 日及出发当天分别核查岛上天气、海上风浪提示和港口航班通知，**“市区不下雨”不能代替开航确认**。

| 情况 | 调整办法 |
| --- | --- |
| 普通阵雨，船班正常 | 把午休、咖啡和用餐挪到下雨时段；步道湿滑就取消登山 |
| 雷雨、大风或景区临时关闭 | 取消登山、礁石活动与下水，待在民宿或镇上室内场所 |
| 去程停航 | 按承运方通知退改船票，拿停航通知联系民宿；当天改深圳市内休闲 |
| 岛上收到返程调整通知 | 先联系船公司与民宿；官方建议提前离岛就优先调整 |
| 返程停航 | 联系民宿续住，按官方恢复安排改签；**不自行找无资质小艇离岛** |

船班咨询：招商蛇口邮轮母港公布渡轮客服 **0755-26691213**。
